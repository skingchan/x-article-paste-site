X 图文粘贴助手隐私政策

发布者：SkingHash · 联系邮箱：weijizg@gmail.com
生效与最近更新日期：2026-10-26

本扩展用于将用户主动粘贴的图文导入 X 文章草稿。正文与图片在浏览器中准备；点击导入后，图片通过当前 X 页面上传给 X。发布者没有用于接收笔记正文或图片的中转服务器。扩展不会自动发布文章。

1. 适用范围

本政策适用于“X 图文粘贴助手”浏览器扩展及本产品说明网站。X、图片来源网站、Chrome 应用商店和 GitHub Pages 的服务由各自运营者提供，其独立的数据处理还受各自政策约束。本产品是独立工具，与 X、印象笔记或 Google 不存在官方隶属关系。

2. 扩展处理哪些信息

  • 主动粘贴内容：用户触发粘贴时提供的文字、HTML、图片引用、图片文件，以及为保留格式所需的样式、链接和顺序。
  • 主动选择的文件：用户选择的原图或文件夹内浏览器允许访问的文件，用于补齐对应图片；不会扫描用户的笔记库或任意磁盘目录。
  • 图片准备信息：原图字节、文件名或来源地址、MIME、图片尺寸、读取结果和导入队列。
  • X 编辑状态：当前文章编辑器的正文块、媒体状态及写入结果，用于空白检查、排序和完整性核对。它可能包含正在编辑的草稿内容。
  • 设置与运行记录：粘贴接管开关保存在本机扩展存储中；当前页面内存保留导入步骤、时间、计数和错误状态，供用户查看或主动导出诊断。

扩展不会持续监控系统剪贴板，不会读取印象笔记账号密码，不会使用 Cookie API 读取或保存 Cookie 值，不建立跨网站浏览历史档案，也不加入广告、行为分析或第三方统计 SDK。

3. 信息用于什么目的

信息仅用于本产品的单一用途：解析来源图文、准备原图、展示预览、识别可恢复的重复占位、导入 X 文章草稿、验证完整性，以及排查用户主动反馈的问题。发布者不出售这些信息，不将其用于广告定向、与产品无关的画像或模型训练。

4. 网络传输与接收方

  • X：用户点击“导入空白正文”后，图片交给 X 当前页面的原生上传流程；正文交给 X 编辑器，其自动保存由 X 完成。X 使用当前登录状态处理上传与草稿。数据保留和删除由 X 服务及用户在 X 中的操作决定。
  • 用户内容指定的图片来源：用户明确允许对应来源后，扩展后台请求该来源的原图。请求会让该来源获知常规网络请求信息，例如 IP 地址、资源路径和浏览器发送的请求头；浏览器可能按自身规则携带该来源已有的登录凭据。发布者不会取得这些凭据的值。
  • 发布者支持邮箱：只有用户自行发送反馈邮件时，发布者才会收到该邮件及用户自行附上的材料。扩展不会自动发送诊断、正文或图片到邮箱。
  • 本说明网站：由 GitHub Pages 托管。我们没有添加分析脚本、广告或表单；GitHub 可能按其政策记录访问所需的网络与服务日志，参见 GitHub 隐私声明。

当前公开发布准备版本只通过 HTTPS 读取网络原图；不自动读取明文 HTTP 来源，也不会把 HTTP 地址静默改成另一个地址。无法读取时可由用户手动选择原图。X 上传使用 X 页面自身的安全连接。

5. 存储、保留与清理

预览和导入数据保留在当前页面的运行内存中，没有自动同步到发布者服务器。清空预览会移除当前预览引用；页面关闭或刷新会结束该页的插件内存会话。浏览器负责实际内存回收，清空预览并不承诺立即物理擦除内存。粘贴接管设置持续保存在本机，直到用户修改、清理扩展数据或卸载扩展。

用户导出的诊断文件由用户自行保存在设备中，需自行删除。X 已经接收或保存的数据不会因清空预览或卸载扩展而被删除，请在 X 中管理相应草稿或文章。若用户主动邮件联系发布者，反馈材料仅保留至支持问题解决及合理后续核对所需期间；可通过上述邮箱申请删除发布者持有的反馈材料。

6. 权限与用户控制

  • scripting：在 X 文章页面运行随安装包提供的编辑器适配代码。
  • storage：保存本机粘贴接管开关。
  • https://x.com/*：显示面板，定位文章编辑器并执行用户发起的导入。
  • 可选 HTTPS 来源权限：仅在用户需要读取网络原图时申请对应来源，不向所有网站注入内容脚本。

用户可以关闭正文粘贴接管、拒绝网络图片权限、手动选图、在开始导入前移除或恢复图片位置、清空预览，或卸载扩展。暂停按钮不承诺取消已经交给 X 的上传。扩展没有自动发布文章的功能。

7. 诊断与可选 Windows 助手

诊断仅在用户点击“导出诊断”时生成本地文件，默认不包含原始正文、图片字节、原始图片地址、账号信息或媒体编号；包含版本、数量、来源类型、尺寸、操作时间、步骤状态和错误说明。异常文本仍建议分享前检查。

可选的 Windows 剪贴板助手不包含在 Chrome 应用商店扩展安装包中，也不是后台常驻服务。若用户另行取得并主动运行助手，它会在按钮点击时读取当前剪贴板 HTML 明确引用、当前用户可访问的本地图片，将它们内嵌后写回剪贴板；不联网、不扫描笔记库。选择文件补图可作为替代方式。

8. 政策变更与联系

若功能或数据用途变化，我们会更新本页面及日期，并在需要时提供相应产品提示。扩展对用户数据的使用遵守 Chrome Web Store 用户数据政策及有限使用要求。隐私问题请联系 weijizg@gmail.com。

Privacy policy — English summary

Publisher: SkingHash. Contact: weijizg@gmail.com. Effective / updated: October 26, 2026. This summary describes the same practices as the Chinese policy above.

X Article Rich Paste processes text, HTML, image references/files, formatting, ordering and the current X article editor state to prepare, preview, import and verify an article draft. It handles clipboard data only when you paste, and files only when supplied through the browser. It does not continuously monitor the system clipboard, scan a notes database, read passwords, access Cookie values through a Cookie API, or build a cross-site browsing history profile.

Article preparation is performed in the browser. The publisher operates no relay server for article text or images. When you click Import, images are passed to X's native upload handler and text to its editor; X handles authentication, saving and retention. Optional network-image requests are made only to origins permitted by you, over HTTPS. Those servers receive ordinary network information, including IP and requested paths, and the browser may send existing origin credentials according to its own rules. No plaintext HTTP image requests are made automatically.

Preview and job data are held in page memory; closing/reloading the page ends the page session. Clearing a preview releases its references without promising immediate secure memory erasure. The paste-interception setting persists locally until changed or extension data is removed. Exported diagnostics are local files initiated by you, normally excluding article text, image bytes, original image URLs, account details and media IDs. You choose whether to share diagnostics. Uninstalling the extension does not delete data already saved by X.

No analytics SDK, advertisements, sale of data, unrelated profiling or model training is used. Feedback reaches the publisher only if you email it; it is retained only as needed for the support matter and reasonable follow-up, and you may request deletion. This website is hosted on GitHub Pages, whose service logs are governed by GitHub's own policy. The optional Windows clipboard helper is distributed separately; if actively used, it reads the current clipboard and explicitly referenced accessible local image files, rewrites the clipboard, and does not network or scan notes. The extension's use of user data complies with the Chrome Web Store User Data Policy, including Limited Use requirements. Contact the publisher with any privacy questions.
