把笔记里的图文，带到 X 文章

X 图文粘贴助手 · 发布者 SkingHash

在印象笔记写好文章，复制后粘贴到插件面板。检查图片，确认导入，文字与图片就会按原顺序进入空白 X 文章草稿。

Chrome 应用商店版本正在准备中。本页提供产品说明与隐私政策，尚未提供商店安装入口。

可以做什么

  • 解析主动粘贴的文字、图片、基本标题、列表、引用与字符格式。
  • 预览原图；缺图时手动选图或在授权后读取 HTTPS 网络原图。
  • 对整篇符合规律的“本地占位＋就绪图片”自动收起多余占位，并允许一次恢复。
  • 先准备全文，再调用 X 原生媒体上传，完成后恢复图文顺序并核对结尾。

使用前提

支持 Chrome / Edge 的兼容浏览器环境；需要用户登录自己的 X 账号并能够使用 X 文章编辑功能。插件仅支持空白文章正文。复杂表格、精确字体排版、音视频和附件不在当前导入范围。

使用流程

  1. 打开 X 文章空白草稿，在印象笔记复制含图片的正文。
  2. 在插件面板按 Ctrl+V，核对图文数量并补齐缺失原图。
  3. 点击“导入空白正文”，保持页面打开，等待“全文已核对”。
  4. 等待 X 保存，再刷新草稿核对；由用户自行决定是否发布。

数据与支持

插件没有自建图文中转服务器，不会自动发布。导入图片会发送给 X；读取网络原图时会访问用户授权的来源。完整说明见 隐私政策。
